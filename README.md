This repository showcases my work on data preprocessing techniques, using weather dataset. 
The project flow involves,

Data Collection and Exploratory Data Analysis (EDA): I started by gathering the dataset and performing EDA to understand the 
data’s structure and key features.

Data Cleaning: Have removed the null and duplicate values. And also have done "Mean imputation" for "Solar R" column. And changed datatypes
wherever required.

Data Transforming: Performed "Label Encoding" on the o/p column "weather". Also tried other technique "One Hot Encoding" using both 
"Pandas" and "Sklearn".
